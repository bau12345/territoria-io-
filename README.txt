TERRITORIA.IO - SPRINT 1
Sistema de autenticación con Supabase.

Incluye login, registro con confirmación por correo, recuperación/cambio de contraseña, cierre de sesión y protección básica de mapa.html.

IMPORTANTE: config.js contiene una clave PUBLICABLE de Supabase. No usar nunca una service_role key en el frontend.

Después de publicar en GitHub Pages, configurar en Supabase > Authentication > URL Configuration la Site URL y las Redirect URLs con la URL real del sitio.
